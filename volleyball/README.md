# Волейбол «№4 × №10»

Браузерная игра «волейбол 3 на 3» для телефона: приём, пас, атака, блок, силовая подача, имена игроков и заставки после очка.

- **Играть:** открыть `index.html` в браузере (или по ссылке GitHub Pages).
- **Команда ИИ-агентов для доработки:** папка `team/` — 11 агентов Claude Code с моделями Opus / Sonnet / Haiku, исходники, сборка и автотесты. Как запустить — в `team/README.md`.
