# ШТОРМ — аниме-волейбол 3D

Браузерный аниме-волейбол 3 на 3: приём, пас по вызову (открытая / быстрая / пайп), удар, суперсилы с cut-in, турнир из трёх матчей с сюжетом. Работает на ПК и на телефоне (горизонтально).

- Запуск: открыть `index.html` через любой статический сервер (нужны `fetch` для моделей).
- Герои собраны скриптом `tools/make_chars.py` (Blender 5.x, `blender -b --python tools/make_chars.py -- assets/chars`).
- Просмотр моделей и анимаций: `tools/viewer.html?id=rei`.
- Самопроверка симуляции: `index.html?selftest`.
